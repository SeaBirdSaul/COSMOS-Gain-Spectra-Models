# Neural Net Prediction Plot Guide

This document describes each plot generated by `plots.py` (singlespan) and `multispan_plots.py` (multispan), what each image represents, and how to read it.

---

## Singlespan Plots

Generated by `plots.py`. Predicts the gain spectrum of a single EDFA span.

### Usage

```bash
python neural_nets/plots.py -t <channel_type>
```

- `-t all` — plot all channel types (one sample per type)
- `-t fully_loaded_channel_wdm` — plot only that type (up to 3 samples)
- Default: `fully_loaded_channel_wdm`

Output goes to `neural_nets/saved_models/singlespan/predictions/graphs/`.

### Plot 01: Predicted vs True Gain Spectra (`01_predicted_vs_true_gain.png`)

**What it shows:** The full 95-channel gain spectrum for one or more samples. Each line represents the gain (in dB) across all 95 channels.

- **Solid lines** = true (measured) gain
- **Dashed lines** = predicted (model output) gain
- **X-axis** = channel number (1–95)
- **Y-axis** = gain in dB

**How to read it:**

- When `-t all`: one solid+dashed pair per channel type. The closer the dashed line follows the solid line, the better the prediction.
- When a specific type: up to 3 samples are shown. Look for where the dashed line deviates from the solid — those are channels the model struggles with.
- Typical gain values are in the range of ~18 dB. Large deviations indicate prediction errors.

---

### Plot 02: Error Heatmap (`02_error_heatmap.png`)

**What it shows:** A 2D heatmap of prediction error (predicted − true) for every channel of every sample. Red = overpredicted, blue = underpredicted.

- **X-axis** = channel number (1–95)
- **Y-axis** = sample index
- **Color** = error in dB (red = positive, blue = negative, white = zero)
- **Color range:** −2 dB to +2 dB

**How to read it:**

- Each row is one sample. Each column is one channel.
- White/near-white cells mean the model predicted well.
- Dark red or dark blue cells are large errors.
- When `-t all`, horizontal black lines separate different channel types, with labels on the right.
- A vertical stripe of color across many samples means a specific channel is consistently hard to predict.

---

### Plot 03: Error Distribution by Channel Type (`03_error_distrinutiom_by_type.png`)

**What it shows:** A boxplot of absolute prediction error (|predicted − true|) grouped by channel type. Shows the spread and median of errors for each type.

- **X-axis** = channel type
- **Y-axis** = absolute error in dB
- **Box** = interquartile range (25th–75th percentile)
- **Orange line** = median
- **Whiskers** = range of non-outlier data
- **Diamonds** = outliers

**How to read it:**

- Short boxes and low medians mean the model is accurate for that type.
- Tall boxes or high medians indicate the model has trouble with that channel configuration.
- Compare types to see which channel patterns are hardest to predict.

---

### Plot 04: Predicted vs True Scatter (`04_predicted_vs_true_scatter.png`)

**What it shows:** A scatter plot comparing predicted gain vs true gain for every channel of every sample. Each dot is one channel in one sample.

- **X-axis** = true gain (dB)
- **Y-axis** = predicted gain (dB)
- **Dashed diagonal line** = perfect prediction (y = x)

**How to read it:**

- Dots on the diagonal = perfect predictions.
- Dots above the line = overpredicted; dots below = underpredicted.
- Tight clustering around the diagonal means good model performance.
- When `-t all`, each channel type gets a different color.
- Spread away from the diagonal shows the magnitude of errors.

---

### Plot 05: Ripple Comparison (`05_ripple_comparison.png`)

**What it shows:** The gain ripple (deviation from the mean active-channel gain) for each channel. Ripple shows the spectral shape/pattern of the gain, ignoring the absolute level.

- **X-axis** = channel number (1–95)
- **Y-axis** = ripple in dB (deviation from the mean active gain)
- **Solid lines** = true ripple
- **Dashed lines** = predicted ripple

**How to read it:**

- A flat line near zero means the gain is very uniform across channels.
- Peaks and valleys show where the gain deviates from average.
- The closer the dashed line follows the solid line's shape, the better the model captures the spectral tilt/ripple pattern.
- This plot is useful for evaluating whether the model learns the _shape_ of the gain spectrum, independent of absolute level.

---

### Plot 06: Error vs Input Power (`06_error_vs_input_power.png`)

**What it shows:** Mean absolute error per sample as a function of total input power. Each dot is one sample.

- **X-axis** = total input power (dB)
- **Y-axis** = mean absolute error across all channels (dB)

**How to read it:**

- Each dot is one measurement sample, averaged across all 95 channels.
- If error increases at certain input powers, the model may not generalize well across the full power range.
- A flat cloud of dots means the model performs consistently regardless of input power.
- When `-t all`, different colors represent different channel types.
- Outliers at high error values indicate specific samples the model handles poorly.

---

## Multispan Plots

Generated by `multispan_plots.py`. Predicts the gain spectrum across multiple ROADM/EDFA stages in a multispan topology.

### Usage

```bash
python neural_nets/multispan_plots.py [-r <roadm_filter>] [-c <channel>]
```

- `-r all` — plot all ROADM stages (default)
- `-r roadm_6_preamp` — filter to a specific ROADM stage
- `-r roadm_1_booster,roadm_6_preamp` — filter to multiple stages
- `-c 48` — plot for a single channel only (1–95)
- Omit `-c` for full spectral plots

Output goes to `neural_nets/saved_models/multispan/predictions/graphs/`. When `-c` is used, output goes to `graphs/ch<N>/` (e.g., `graphs/ch1/`).

### Full Spectral Mode (no `-c` flag)

#### Plot 01: Predicted vs True Gain Spectra (`multispan_01_predicted_vs_true_gain.png`)

**What it shows:** The full 95-channel gain spectrum for one or more ROADM stages. Each line represents the gain (in dB) across all 95 channels.

- **Solid lines** = true (measured) gain
- **Dashed lines** = predicted (model output) gain
- **X-axis** = channel number (1–95)
- **Y-axis** = gain in dB

**How to read it:**

- When `-r all`: one solid+dashed pair per ROADM type (one sample each). The closer the dashed line follows the solid line, the better.
- When filtered to a specific ROADM: up to 3 samples are shown.
- The gain data stored in the predictions is **ripple** (deviation from the mean active-channel gain), so values are small (roughly −0.5 to +0.3 dB), not absolute gain (~18 dB).

---

#### Plot 02: Error Heatmap (`multispan_02_error_heatmap.png`)

**What it shows:** A 2D heatmap of prediction error (predicted − true) for every channel of every sample across ROADM stages.

- **X-axis** = channel number (1–95)
- **Y-axis** = sample index
- **Color** = error in dB (red = positive, blue = negative)
- **Color range:** −2 dB to +2 dB

**How to read it:**

- Each row is one sample. Horizontal black lines separate different ROADM stages (when `-r all`).
- Consistent vertical stripes indicate channels that are systematically mispredicted across many samples.
- Check whether certain ROADM stages have more intense colors (larger errors) than others.

---

#### Plot 03: Error Distribution by ROADM Type (`multispan_03_error_distrinutiom_by_type.png`)

**What it shows:** A boxplot of absolute prediction error grouped by ROADM stage.

- **X-axis** = ROADM stage (e.g., `roadm_1_booster`, `roadm_6_preamp`)
- **Y-axis** = absolute error in dB
- **Box** = interquartile range
- **Orange line** = median
- **Whiskers** = range of non-outlier data

**How to read it:**

- Compare box heights across ROADM types to see which stages the model predicts most/least accurately.
- A narrow, low box means consistent, low errors for that stage.
- A wide or tall box means high variance in prediction quality.

---

#### Plot 04: Predicted vs True Scatter (`multispan_04_predicted_vs_true_scatter.png`)

**What it shows:** A scatter plot of predicted vs true for every channel of every sample.

- **X-axis** = true gain (dB)
- **Y-axis** = predicted gain (dB)
- **Dashed diagonal** = perfect prediction

**How to read it:**

- Same interpretation as singlespan: dots on the diagonal are correct predictions.
- When `-r all`, each ROADM type has its own color. You can see if certain types cluster more tightly around the diagonal.
- Outliers far from the diagonal indicate problematic samples.

---

#### Plot 05: Ripple Comparison (`multispan_05_ripple_comparison.png`)

**What it shows:** The gain ripple (deviation from mean active-channel gain) for one sample per ROADM type.

- **X-axis** = channel number (1–95)
- **Y-axis** = ripple in dB
- **Solid lines** = true ripple
- **Dashed lines** = predicted ripple

**How to read it:**

- Evaluates whether the model captures the spectral shape pattern across each ROADM stage.
- The closer the dashed line tracks the solid line's peaks and valleys, the better.
- Flat lines near zero indicate uniform gain across channels.

---

#### Plot 06: Error vs Input Power (`multispan_06_error_vs_input_power.png`)

**What it shows:** Mean absolute error per sample as a function of total input power.

- **X-axis** = total input power (dB)
- **Y-axis** = mean absolute error across all channels (dB)

**How to read it:**

- Each dot is one sample. When `-r all`, different colors = different ROADM types.
- A pattern where error increases with power suggests the model struggles at certain power levels.
- Outliers at the top indicate samples with unusually high error.

---

### Single-Channel Mode (`-c <N>`)

When `-c` is provided, all 6 plots are adapted to show data for a single channel across ROADM types.

#### Plot 01: Gain Bar Chart (`multispan_01_predicted_vs_true_gain.png`)

**What it shows:** Grouped bar chart comparing predicted vs true gain for one channel, averaged across samples of each ROADM type.

- **X-axis** = ROADM types
- **Y-axis** = gain (dB)
- **Left bar (blue)** = true mean gain
- **Right bar (orange)** = predicted mean gain
- **Error bars** = ±1 standard deviation across samples

**How to read it:**

- Compare bar heights for each ROADM type. Similar heights = good prediction.
- Error bars show how much the channel's gain varies across different samples of that ROADM type.
- The title shows which channel number is plotted (e.g., "Ch 48").

---

#### Plot 02: Error Per Sample (`multispan_02_error_heatmap.png`)

**What it shows:** A bar chart of prediction error (predicted − true) for every individual sample, colored by ROADM type.

- **X-axis** = sample index
- **Y-axis** = error in dB
- **Bar color** = ROADM type (see legend)

**How to read it:**

- Bars above zero = overpredicted; bars below zero = underpredicted.
- Color grouping shows which ROADM types the model handles well or poorly.
- A large bar in one color means that specific sample/type has high error.

---

#### Plot 03: Error Distribution (`multispan_03_error_distrinutiom_by_type.png`)

**What it shows:** Boxplot of absolute error for the selected channel, grouped by ROADM type.

- **X-axis** = ROADM type
- **Y-axis** = absolute error in dB

**How to read it:**

- Narrow, low boxes = the model predicts this channel consistently well for that ROADM type.
- Wide or tall boxes = high variance in prediction quality for this channel.
- Same interpretation as spectral mode, but scoped to one channel.

---

#### Plot 04: Scatter (`multispan_04_predicted_vs_true_scatter.png`)

**What it shows:** Scatter of predicted vs true gain for the single channel, one dot per sample.

- **X-axis** = true gain (dB)
- **Y-axis** = predicted gain (dB)
- **Dashed diagonal** = perfect prediction
- **Colors** = ROADM types

**How to read it:**

- Tight clustering around the diagonal = good prediction for this channel.
- If one color group is offset from the diagonal, the model has a systematic bias for that ROADM type on this channel.

---

#### Plot 05: Ripple Comparison (`multispan_05_ripple_comparison.png`)

**What it shows:** Line graph of mean ripple for the selected channel across ROADM types.

- **X-axis** = ROADM types
- **Y-axis** = ripple in dB
- **Solid line with circles (`o-`)** = true mean ripple
- **Dashed line with squares (`s--`)** = predicted mean ripple
- **Shaded bands** = ±1 standard deviation across samples

**How to read it:**

- Ripple for a single channel is computed as: `channel_gain − mean(active_channel_gains)` for each sample.
- Lines close together = model captures the ripple pattern well.
- Diverging lines = the model's ripple prediction differs from reality.
- Wide shaded bands = high variance across samples; narrow bands = consistent behavior.
- Zero on the y-axis means this channel's gain is at the average of all active channels.

---

#### Plot 06: Error vs Input Power (`multispan_06_error_vs_input_power.png`)

**What it shows:** Absolute error for the single channel as a function of total input power.

- **X-axis** = total input power (dB)
- **Y-axis** = absolute error in dB (for this channel)
- **Colors** = ROADM types

**How to read it:**

- Each dot is one sample. Look for trends where error increases or decreases with power.
- If one ROADM type (color) consistently has higher error, the model underperforms for that stage at this channel.
- Outliers at the top are specific samples with high error for this channel.
