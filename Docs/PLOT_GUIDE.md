# Neural Net Prediction Plot Guide

This guide explains the plotting workflow for the repository’s different model families and makes the current status explicit: the encoder workflow is the active production path, while the older single-span and multispan plot scripts remain useful as legacy diagnostics.

## Overview of the plotting scripts

### Current production workflow

- [neural_nets/encoder_plots_v2.py](../neural_nets/encoder_plots_v2.py)
- used for the active encoder model trained in [neural_nets/encoder_net.py](../neural_nets/encoder_net.py)
- writes plots for the encoder predictions saved in `neural_nets/saved_models/encoder/predictions/`

### Legacy workflows

- [neural_nets/plots.py](../neural_nets/plots.py)
- [neural_nets/multispan_plots.py](../neural_nets/multispan_plots.py)
- these are older plotting tools for the legacy single-span and multispan model families
- they are still usable for older saved outputs, but they are not the current primary evaluation workflow

---

## Encoder plots: current model

The active encoder model is defined in [neural_nets/encoder_net.py](../neural_nets/encoder_net.py). Its plots are generated by [neural_nets/encoder_plots_v2.py](../neural_nets/encoder_plots_v2.py), and the expected output layout is in the model prediction directory under `.../saved_models/encoder/predictions/graphs/...`.

### Usage

```bash
python neural_nets/encoder_plots_v2.py --path <path/to/predictions_json> --output-dir <output_dir>
```

Optional filters:

```bash
python neural_nets/encoder_plots_v2.py --path <path/to/predictions_json> -r roadm_2_preamp --output-dir <output_dir>
python neural_nets/encoder_plots_v2.py --path <path/to/predictions_json> -c 1 --output-dir <output_dir>
```

### What the encoder plots show

#### 01. Predicted vs True Gain Spectra

- one sample per ROADM stage or a filtered subset
- solid line = true spectrum
- dashed line = predicted spectrum
- useful for checking whether the model tracks the full spectral pattern

#### 02. Error Heatmap

- 2D map of prediction error = predicted − true
- x-axis = channel
- y-axis = sample index
- color scale highlights under-/over-prediction
- excellent for spotting edge-channel errors and stage-specific bias

#### 03. Error Distribution by ROADM Stage

- boxplot of absolute error grouped by ROADM
- identifies which stages are systematically harder

#### 04. Predicted vs True Scatter

- each point is a channel prediction
- diagonal line indicates perfect prediction
- useful for seeing compression or bias away from the ideal line

#### 05. Ripple Comparison

- compares true and predicted ripple values by channel
- helps diagnose whether the model captures shape, not just mean level

#### 06. Error vs Input Power

- scatter of mean absolute error against input power
- checks whether poor performance is concentrated in low-power or high-power operating regions

#### 07. ROADM Stage Proficiency

- bar chart of mean error per ROADM stage
- summarizes which stages need more attention or more data

### Encoder output naming

The script writes files such as:

- `encoder_01_predicted_vs_true_gain.png`
- `encoder_02_error_heatmap.png`
- `encoder_03_error_distribution_by_type.png`
- `encoder_04_predicted_vs_true_scatter.png`
- `encoder_05_ripple_comparison.png`
- `encoder_06_error_vs_input_power.png`
- `encoder_07_roadm_proficiency.png`

This is the current standard evaluation output for the project.

## Legacy singlespan plots

The legacy single-span workflow lives in [neural_nets/plots.py](../neural_nets/plots.py). It reads a saved predictions JSON under the singlespan model directory and creates a full 6-plot set.

### Usage

```bash
python neural_nets/plots.py -t all
python neural_nets/plots.py -t fully_loaded_channel_wdm
```

### What these plots show

These plots are similar to the encoder plots but target the older single-span data model:

- gain comparison across channel types
- error heatmap
- distribution by channel type
- predicted vs true scatter
- ripple comparison
- error vs input power

This workflow is useful for historical comparisons and debugging old single-span experiments, but it is not the current recommended analysis method for the multispan EDFA dataset.

## Legacy multispan plots

The older multispan plot script is [neural_nets/multispan_plots.py](../neural_nets/multispan_plots.py). It is intended for the legacy multispan model family and uses a saved predictions file under the multispan model directory.

### Usage

```bash
python neural_nets/multispan_plots.py -r all
python neural_nets/multispan_plots.py -r roadm_2_preamp
python neural_nets/multispan_plots.py -c 48
```

### What these plots show

- predicted vs true spectra per ROADM
- error heatmap across channels and samples
- error distribution per ROADM stage
- predicted vs true scatter
- ripple comparison
- error vs input power
- single-channel mode with `-c`

### Current status

This script is still valid for the older stage-aware multispan model family and can be used as a legacy reference. However, the current project evaluation uses [neural_nets/encoder_plots_v2.py](../neural_nets/encoder_plots_v2.py) as the canonical graphics workflow because it matches the active encoder model and the reporting pipeline summarized in [Docs/REPORT.md](REPORT.md).

## Interpretation guide

When reading any of the plots, the main questions are:

- is the error concentrated in a small number of channels?
- does one stage behave much worse than the others?
- does performance get worse at low power?
- does the model flatten or compress the ripple?
- are the errors mostly at the band edges?

For this project, the key failure pattern is often spectral tail behavior, especially on edge channels like channel 1 and the high-channel end, rather than a broad average failure across all stages.

## Recommended workflow

For the current project, use this order:

1. Train/predict with [neural_nets/encoder_net.py](../neural_nets/encoder_net.py)
2. Evaluate with [neural_nets/encoder_metrics.py](../neural_nets/encoder_metrics.py)
3. Plot with [neural_nets/encoder_plots_v2.py](../neural_nets/encoder_plots_v2.py)
4. Use [neural_nets/multispan_plots.py](../neural_nets/multispan_plots.py) and [neural_nets/plots.py](../neural_nets/plots.py) only for legacy comparisons or older model outputs

#### Plot 01: Predicted vs True Mean Gain (`multispan_01_predicted_vs_true_gain.png`)

**What it shows:** Bar chart comparing true and predicted mean gain for a selected channel across ROADM types.

- **Left bar (blue)** = true mean gain
- **Right bar (orange)** = predicted mean gain
- **Error bars** = ±1 standard deviation across samples

**How to read it:**

- Compare bar heights for each ROADM type. Similar heights = good prediction.
- Error bars show how much the channel's gain varies across different samples of that ROADM type.
- The title shows which channel number is plotted (e.g., "Ch 48").

---

#### Plot 02: Error Per Sample (`multispan_02_error_heatmap.png`)

**What it shows:** A bar chart of prediction error (predicted − true) for every individual sample, colored by ROADM type.

- **X-axis** = sample index
- **Y-axis** = error in dB
- **Bar color** = ROADM type (see legend)

**How to read it:**

- Bars above zero = overpredicted; bars below zero = underpredicted.
- Color grouping shows which ROADM types the model handles well or poorly.
- A large bar in one color means that specific sample/type has high error.

---

#### Plot 03: Error Distribution (`multispan_03_error_distribution_by_type.png`)

**What it shows:** Boxplot of absolute error for the selected channel, grouped by ROADM type.

- **X-axis** = ROADM type
- **Y-axis** = absolute error in dB

**How to read it:**

- Narrow, low boxes = the model predicts this channel consistently well for that ROADM type.
- Wide or tall boxes = high variance in prediction quality for this channel.
- Same interpretation as spectral mode, but scoped to one channel.

---

#### Plot 04: Scatter (`multispan_04_predicted_vs_true_scatter.png`)

**What it shows:** Scatter of predicted vs true gain for the single channel, one dot per sample.

- **X-axis** = true gain (dB)
- **Y-axis** = predicted gain (dB)
- **Dashed diagonal** = perfect prediction
- **Colors** = ROADM types

**How to read it:**

- Tight clustering around the diagonal = good prediction for this channel.
- If one color group is offset from the diagonal, the model has a systematic bias for that ROADM type on this channel.

---

#### Plot 05: Ripple Comparison (`multispan_05_ripple_comparison.png`)

**What it shows:** Line graph of mean ripple for the selected channel across ROADM types.

- **X-axis** = ROADM types
- **Y-axis** = ripple in dB
- **Solid line with circles (`o-`)** = true mean ripple
- **Dashed line with squares (`s--`)** = predicted mean ripple
- **Shaded bands** = ±1 standard deviation across samples

**How to read it:**

- Ripple for a single channel is computed as: `channel_gain − mean(active_channel_gains)` for each sample.
- Lines close together = model captures the ripple pattern well.
- Diverging lines = the model's ripple prediction differs from reality.
- Wide shaded bands = high variance across samples; narrow bands = consistent behavior.
- Zero on the y-axis means this channel's gain is at the average of all active channels.

---

#### Plot 06: Error vs Input Power (`multispan_06_error_vs_input_power.png`)

**What it shows:** Absolute error for the single channel as a function of total input power.

- **X-axis** = total input power (dB)
- **Y-axis** = absolute error in dB (for this channel)
- **Colors** = ROADM types

**How to read it:**

- Each dot is one sample. Look for trends where error increases or decreases with power.
- If one ROADM type (color) consistently has higher error, the model underperforms for that stage at this channel.
- Outliers at the top are specific samples with high error for this channel.

---

#### Plot 07: ROADM Stage Proficiency (`multispan_07_roadm_proficiency.png`)

**What it shows:** Bar chart of mean absolute error by ROADM stage, summarizing which stages are hardest for the model.

- **X-axis** = ROADM stage or stage category
- **Y-axis** = mean absolute error in dB
- **Bars** = one value per stage / subsection of the network

**How to read it:**

- Lower bars = better performance at that stage.
- Larger bars indicate a systematic weakness in that stage or operating condition.
- This is a quick way to identify whether the model is failing in one bottleneck section rather than across the whole system.

---

## Conclusion

This guide is intended to make the plotting workflow readable in the same order the model is usually evaluated: first check whether the spectra are tracking the true shape, then inspect residual behavior, then narrow to stage-specific or channel-specific issues. For the active encoder workflow, the most informative plots are the per-sample comparisons, error heatmaps, and stage-level summaries because they reveal whether the model is failing in a few edge channels or in a specific ROADM segment.

In practice, the strongest project workflow is:

1. train and predict with the encoder model
2. review the held-out metrics
3. inspect the 7-plot encoder set for channel and stage patterns
4. use the legacy plot families only for historical comparisons or older model families

The goal is always to determine whether a model is broadly accurate or whether it is systematically biased at the network edges, on particular ROADM stages, or under specific operating conditions.
